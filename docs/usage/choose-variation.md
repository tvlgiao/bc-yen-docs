# Choosing a variation

Yen Theme ships three variations. They are the same theme with different settings, so
switching between them changes only appearance, never structure or features.

| Variation | What it changes | Settings it overrides |
| --- | --- | --- |
| **Light** | Nothing — this is the theme's own defaults | 0 |
| **Bold** | High-contrast palette, heavier type, dark default mode | 61 |
| **Warm** | Earth-toned palette applied throughout | 195 |

Switch variations in **Theme Editor → the variation dropdown at the top**. Note that
switching resets any setting the target variation defines, so make your variation choice
before spending time on colours.
